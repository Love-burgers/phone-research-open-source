# 多轮选机助手（0.4.0，尚未发布）

首页记录预算、用途、品牌、排除、数量、游戏和硬条件。默认给两三款有依据的备选，每款一块、一两句话；不足时少给。补充用途细节接着当前候选回答；新增用途保留原条件；修改条件实际重新核对；换批寻找上一批外的选择，不永久排除旧机型。已知条件不重复问。

## 接口与持久化

- `POST /api/chat/sessions` 新建；`POST /api/chat` 接收 message、可选 session_id 与 search_mode。
- `GET /api/chat/sessions/{session_id}` 恢复；`DELETE` 同路径删除。不存在返回 404，并发 revision 冲突返回 409，资料/存储不可用返回 503。
- 返回 profile、messages、revision 和会话内 discovered_phones。消息包含 content、blocks、followup、sources、cards、suggestions、mode、details 和可选 agent_trace。
- `search_mode=local/web/auto`，省略为 auto。页面联网开关默认关闭；明确要求不联网优先。显示区分实际联网、缓存、本地和未执行，不能只按按钮推定成功。
- SQLite 默认 `runs/chat-sessions.sqlite3`，可配置 CHAT_STORAGE_PATH。只保留最近 30 轮消息，条件独立持久化；不是 LangGraph checkpoint。
- 浏览器保存会话编号和开关，可用 `/?session=会话编号` 恢复。旧消息字段有默认值，不改写历史回答；旧条件仅从用户原话恢复缺失字段。

完整品牌和数字型号可注册为会话线索，最多 20 个；基础版、Pro、Pro+ 等独立核对。注册名称不证明产品存在。明确比较名单独立存储，不因普通条件变化直接清空；序号依照上一轮实际展示顺序解析，指代不明时澄清。

## 资料与回答

默认公开索引 `app/knowledge_samples/selection_index.json` 包含 98 款/455 片段，BM25 无需网络和向量下载。5 款初始候选目录不代表全部可检索范围；外部向量索引可通过 CHAT_KNOWLEDGE_INDEX_PATH 加载，混合检索使用 RRF。资料数量、向量检索与事实正确率分别看待。

page 是抓取正文，knowledge 是本地摘录，snippet 仅为线索。官网参数用于初筛，review 才可能支持实际体验；容量不代表续航、芯片不代表帧率、像素不代表成片。正文保留有据参数与关键取舍；日期、普通版本价缺口和缺实测提醒放可展开详情，影响选择的预算或来源冲突仍简短说明。

版本价格需要来源正文与明确版本，区分大陆和其他地区、官网和非官网。价格是有日期的页面记录，不能当作实时到手价。参数校验只覆盖常见数值单位；引用存在不等于整句语义获证实。

Agent 自主决定查询。CHAT_AGENT_ENABLED=0 或模型不可用时使用固定资料路径，两者共享回答校验。六小时缓存复用查询与正文，明确刷新绕过缓存；失败保留其他可用证据。同页正文更新保留引用编号，不把重复正文当成新增进展。

## 验证边界

离线回归覆盖多轮条件、取消、指代、换批、旧会话、来源冲突、空结果、工具失败、引用与存储边界。它证明程序在测试输入和模型输出下的行为，不能证明真实模型稳定理解，也不是推荐准确率。真实运行必须事先限定新场景和总调用数，保存失败、原始输入输出、来源、轨迹及用量，不复用旧额度。

修过的原题属于回归集。真正留出题需要独立准备、限制开发时可见性并锁定版本，当前没有新的真实盲测结论。历史人工判断保留在开发者本地，未随公开版发布。[Agent 机制](AGENT.md) 与 [架构](ARCHITECTURE.md) 描述当前实现。

当前实现还会把本轮语义focus_topics与完整条件分开保存，压缩最终请求但保留完整来源注册表。相机列表按标签/数值方向绑定镜头角色，屏幕和触控频率、有线/无线充电分别核对。真实12次请求的失败保存在 runs/resolution-20261023/live；后续修复只做离线回放，不把它改判为新版本真实通过。
