# 多轮选机助手（0.4.0，尚未发布）

首页记录预算、用途、品牌、排除、数量、游戏和硬条件。默认给两三款有依据的备选，每款一块、一两句话；不足时少给。补充用途细节接着当前候选回答；新增用途保留原条件；修改条件实际重新核对；换批寻找上一批外的选择，不永久排除旧机型。已知条件不重复问。

## 接口与持久化

- `POST /api/chat/sessions` 新建；`POST /api/chat` 接收 message、可选 session_id 与 search_mode。
- `GET /api/chat/sessions/{session_id}` 恢复；`DELETE` 同路径删除。不存在返回 404，并发 revision 冲突返回 409，资料/存储不可用返回 503。
- 返回profile、messages、revision和会话内discovered_phones。profile的answer_requirements独立保存测试条件、核对日期等证据偏好，旧记录默认空列表；不参与硬件资格。消息包含content、blocks、followup、sources、cards、suggestions、mode、details及可选agent_trace。
- block的evidence_ids引用本机事实；可选background_ids默认空列表，引用已登记的其他对象资料。背景内容另起一句注明原机型/对象，界面单列背景链接，不作为本机实测。缺引用或明确的单块结构错误可用已核实字面前提做有界修正，随后重新校验全部结论；显式错误/跨机型编号不盲目替换。原草稿、拒绝及修正轨迹保留。
- `search_mode=local/web/auto`，省略为auto。页面提供“关闭查询/按需查询/本轮查询”，默认local，兼容原API和浏览器保存的local/web选择。local禁止新增公开访问但复用会话网页正文；auto允许按缺口决定；web请求本轮至少尝试一次公开查询，不等于刷新缓存。明确“不联网/只用已有资料”优先。网页权限不关闭聊天模型；选配远程Embedding也可能联网。轨迹分别显示本地/会话/缓存/公开操作、失败与未执行，不将工具操作数当作底层HTTP总数。
- SQLite 默认 `runs/chat-sessions.sqlite3`，可配置 CHAT_STORAGE_PATH。只保留最近 30 轮消息，条件独立持久化；不是 LangGraph checkpoint。
- 浏览器保存会话编号和开关，可用 `/?session=会话编号` 恢复。旧消息字段有默认值，不改写历史回答；旧条件仅从用户原话恢复缺失字段。

完整品牌和数字型号可注册为会话线索，最多20个；基础版、Pro、Pro+分别核对。注册不证明产品存在。selected_phones仅表示本轮关注；明确限定/比较或只输入一份型号名单才固定范围，详情询问不固定。candidate_scope=retain/restrict/release表达范围操作，变更需本轮逐字引用。普通预算变更保留真正固定的比较名单以讨论冲突；turn_action=recommend即可重新筛选并释放旧范围，无需冗余reselect。序号依上一轮实际展示顺序解析，含糊指代先澄清。

## 资料与回答

默认公开索引 `app/knowledge_samples/selection_index.json` 包含102款/478片段（389参数、73价格、16评测），BM25无需网络和模型下载。20款有价格、7款有评测；五款初始目录不代表全部检索范围。外部向量索引用CHAT_KNOWLEDGE_INDEX_PATH加载，可选本地BGE与RRF混合检索；旧外部索引不自动同步补录。资料范围见 [CORPUS](CORPUS.md)。

page是抓取正文，knowledge是本地摘录，snippet仅为线索。区分已核实事实、基于事实的判断、未核实项。有同机处理器/GPU、显示、散热、影像或电池配置即可作有理由、有不确定性说明的用途初判；缺少同机实测不单独取消推荐资格。引用支持事实前提，不要求来源逐字写好模型判断。容量不能证明具体续航时长，高刷屏不能证明游戏开放或达到相同帧率；具体FPS、温度、续航等数字仍须对应对象、条件与数值证据。背景或别机测试不冒充本机实测。日期与一般缺口放详情，影响选择的预算、版本及来源冲突仍简短说明。

本轮task的overview区分总体适配评价与具体题材/实测追问。裸型号、空格/大小写变体和“怎么样/适合我吗”沿用当前对象与用途，复用已有相关事实和分析，不把整句问法当作必须逐字匹配的测试场景。具体实测问题继续保留按游戏、设备温度、功耗等分项缺口。模型不可用或结构错误时，资料兜底提供可引用事实、透明的配置初判与未知项，不伪装为新的模型分析。

版本价需正文与明确版本，区分市场、官网与非官网、建议价与优惠到手价。有限非数值属性和常见数值门槛使用满足/不满足/未知/来源冲突四种核对状态：明确不满足不得成为合格推荐，未知不冒充满足，显式比较仍可带缺口讨论。模型与规则共用按属性合并的条件逻辑：复合条件拆开，改重量或取消无线不删除其他属性；保留原话跨度，不把整轮输入回填成一条要求。网页权限与证据/回答要求不进入产品门槛；未支持的明确硬要求仍待核。引用存在不等于整句语义获证实，布尔功能结论也须与所引正文一致。

Agent自主决定工具与结束时机。CHAT_AGENT_ENABLED=0或模型不可用时使用有界固定资料路径；两者共享完整型号边界、会话证据、来源合并/淘汰及回答校验。固定采集复用同一搜索/正文适配器，受本轮查询额度限制，不静默切换引擎。关闭网页查询不影响已保存正文的摘录回答。

本轮工具、模型、公开搜索和网页读取次数分别由 `CHAT_TURN_TOOL_CALLS=18`、`CHAT_TURN_MODEL_CALLS=10`、`CHAT_TURN_SEARCH_CALLS=6`、`CHAT_TURN_FETCH_CALLS=8` 配置，与每日 Token、每日模型请求及每日对话额度分开。工具总次数包含本地检索和公开操作；停止说明显示实际用量与上限。Token、上下文、时限及无进展边界继续独立生效。

版本报价的地区上下文取自同机型报价段落；明确大陆渠道和人民币金额可识别为大陆报价，不能据此证明硬件国行版本。领券、补贴、换新等条件价不作为无条件版本报价。旧促销页面即使今天读取也不能成为今天可购价；历史参考及具体优惠条件仍保留在来源和说明中。区分尚未读取报价正文、地区/版本对应未知、已核报价超预算、仅有历史促销。仅缺报价时，继续核价沿用已有条件，不重复要求用户更换品牌或用途。

有对应配置和预算内的版本参考报价时，可进入明确标注的初步备选。历史促销时效及刷新未完成属于价格说明，不再单独否决整份初筛；没有任何预算内参考版本、已知超预算或明确硬条件未通过仍不进入合格初筛。区分手机售价、补贴上限、优惠额、运费和赠品价值，历史展示保留原文小数，版权区重复标题不生成第二笔报价。本地初筛检查完整有界索引库存，优先已有预算内价格和相关配置，调用方 limit=5 就允许返回五款供模型选择，不在内部缩成三款或两款待查线索。

AI 路径的首轮价位候选也使用索引中的有依据价位与配置线索，不只使用种子目录；跨会话缓存仅存索引派生资料，返回会话副本，实际引用正文后才记录到当前会话。定向本地查询会补入同机型已有的用途配置和相应报价，避免短查询词不匹配就返回空结果。模型少选时，只在已取得正文且同样通过预算、版本、排除与硬条件检查的范围内补齐目标数量，轨迹记录补充候选；不以未核假设凑数。已有适配判断不再重复追加整段通用分析，候选变少后不保留“前两款”等失效比较，也不无依据声称“这批唯一”。

未核到现价且正文没有列出报价时，`price_references` 以独立的“历史价格参考（当前价格未核实）”区域直接展示有正文支持的历史报价，保留版本、原日期、渠道及优惠条件和来源链接。它与已通过当前条件核对的 `blocks/cards` 分开，不增加合格推荐名额，也不改变预算或把优惠资格视为已满足；同型号已有当前可用报价时不重复列旧促销价。

正文已经列出同型号报价时，不再重复展示整块历史价格；机型正文旁保留简短核对日期及现价待确认提示，完整记录收进“其他版本与价格记录”。正文没有金额的机型继续直接展示历史价。这个显示规则也适用于已保存的历史消息，不改会话数据或原报价。

刷新按用户明确字段/类型执行：price/spec/review，未指定类型才是整类刷新。ChatSource的refresh_status旧记录默认not_requested；pending/verified/failed/not_permitted/not_attempted分别表示待确认、已取得新正文、未取得新记录、未允许、未执行；superseded表示同源同版本已有较新记录。按机型、来源和版本归并刷新结果，部分成功与整体失败分开。旧价格保原日期，配置/评测不因价格刷新清空，不同来源冲突不静默覆盖。

网页短字段与邻接值共同提取，保持否定和所属机型小节。review表示来源作者报告的有对象、条件、结果的测试或观察，标题只作辅助，不代表独立核验。验证码、访问阻断、无正文、无相关段落、型号不匹配、无匹配搜索和额度结束分别反馈。详情/询价失败不被通用推荐失败文案覆盖。见 [联合修复记录](NETWORK_REPAIR_20261024.md)。

## 验证边界

离线回归覆盖多轮条件、取消、指代、换批、旧会话、来源冲突、空结果、工具失败、引用与存储边界。它证明程序在测试输入和模型输出下的行为，不能证明真实模型稳定理解，也不是推荐准确率。真实运行必须事先限定新场景和总调用数，保存失败、原始输入输出、来源、轨迹及用量，不复用旧额度。

修过的原题属于回归集。真正留出题需独立准备、限制开发时可见性并锁定版本；当前没有新的真实盲测结论。私人运行和人工判断不公开。[Agent机制](AGENT.md)、[架构](ARCHITECTURE.md)和 [修复记录](REPAIR_20261024.md)描述当前实现及验证范围。

本轮task统一记录推荐/比较/询价/字段/详情、机型范围、数量、主题、游戏与网页权限；下游消费相同任务。逐块校验模型原稿与兜底，不因一个坏块放宽其他块引用；字段未知与型号无资料分开。任务进展以目标缺口变化计算，已扫描的本地缺口不靠相近词反复查询。历史真实失败保持原判，不把后续离线回归改称新版本真实通过。集中修复与验证见[逻辑修复记录](LOGIC_REPAIR_20261025.md)。
