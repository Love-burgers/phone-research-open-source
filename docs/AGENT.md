# 对话选机 Agent

模型决定工具、参数、后续动作和结束时机。代码负责执行边界、同型号来源登记、条件核对与回答校验；没有按示例写死的工具顺序或候选答案。

`chat_intent.py` 使用已有条件和实际展示的最近对话提取本轮增量；`conversation_policy.py` 根据真实增量和候选状态路由。细化原用途保留其他条件与当前候选；预算、品牌、用途、数量或硬要求变化重新核对。换批暂避上一批，不永久排除旧机型。语义抽取仍可能失败，动作枚举不证明真实理解稳定。

`chat_agent.py` 的 `ChatAgentRun` 显式持有单轮依赖与状态。`execute` 校验工具和额度后分派；各工具、`record_sources`、`candidate_state`、`validate_finish`、`read_decision`、`select_candidates`、`compose_reply` 分别承担可测试的职责。共享的 `AnswerComposer` 负责回答生成、逐块校验、资料兜底与展示，Agent 和固定路径采用相同校验。

默认每轮最多 8 次工具尝试、6 次模型请求（含理解、候选选择和回答）、3 次公开搜索、4 次选定页面读取；连续 3 批无进展停止。HTTP 与已知搜索 meta 跳转属于一次有界读取，合计默认最多3跳，逐跳检查公开地址，不执行脚本或自动打开普通链接；保存最终引用URL、读取步骤和缓存/网络操作数。搜索引擎失败不暗中换引擎，由模型看反馈决定。无匹配公开结果、空正文/验证页的提取和原始HTML缓存都短期保留，期限耗尽不写成来源故障。单次请求上下文上限 64000 字符、单轮累计执行预算 64000；按 UTF-8 字节保守预留，再以真实 usage 结算，并非模型原生窗口或严格费用。默认带最近 12 轮、历史文本额度 12000 字符，规划压缩后最多 8000、回答阶段最多 6000；结构化条件独立持久化。容量可由 `.env.example` 中 `CHAT_CONTEXT_CHARACTERS`、`CHAT_TURN_TOKEN_BUDGET`、`CHAT_HISTORY_MESSAGES`、`CHAT_HISTORY_CHARACTERS` 配置。压缩依据实际剩余预算和工具 schema 大小，保留候选顺序、失败反馈、未打开正文链接和来源边界。请求间检查 120 秒期限，并非整个 HTTP 请求的严格中断保证。无效和重复请求也计尝试。封存验证的总请求上限独立于每轮工具次数。

`search_local_phones` 跨机型发现本地资料；`search_phone_knowledge` 追问具体型号；`consider_phones` 提出待验证假设；`discover_phones` 查找新型号线索；`web_search` 与 `fetch_page` 查询并核对正文。仅本地模式禁用公开工具；联网模式要求模型选择有用公开查询。缓存、失败与实际联网状态分别记录，公开工具次数不等于底层 HTTP 次数。

phone_identity统一品牌别名、大小写/空白和中英文变体边界，供预览、正文、来源登记、本地型号过滤和历史链接复用使用；不擅自把不同市场的中文版本名翻译成同一国际型号。知识库既有片段ID不因查询归一化重建。

evidence_registry将会话历史、本地检索和新网页证据接入同一合并规则。Agent仍自主选择工具；固定路径先合并历史和本地证据，再按当前问题缺口与权限补查。局部刷新保留其他类型，历史价格带日期/状态，模型声称“最新价”仍须当前有效引用支持。默认BM25不自动吸收网页，不妨碍会话复用；第三方评测仍不自动写入公共索引。故障反馈及验证范围见 [联合修复](NETWORK_REPAIR_20261024.md)。

URL必须来自同会话同机型线索并通过公网校验。来源登记每款最多八条工作证据，按价格、硬要求、用途覆盖、正文类型与日期替换低价值材料；满额不阻止关键新正文。相反属性和同版本异价保留冲突。摘要升级/同页更新复用原ID，新URL使用独立ID，轨迹记录替换，历史回答保留各自引用快照。参数、价格、评测分角色使用：配置可以支持带依据与不确定性的初步适配判断，不能冒充测量。推荐前核对预算、容量、硬要求和各用途依据；缺同机实测不单独否决，硬门槛未知仍不能算满足。明确比较/详情可带缺口讨论。

selected_phones只表达本轮关注，candidate_scope表达固定/释放选机范围；范围操作需逐字引用。详情不新增固定名单，真正比较名单在预算冲突讨论中保留；未指定机型范围的明确推荐可重新筛选，不依赖额外reselect布尔值，“从这两款中推荐”仍在被指代名单内讨论。有限属性使用统一RequirementCheck（satisfied/unsatisfied/unknown/conflict），候选状态同时返回证据ID与URL。支持屏幕形态、无线充电、NFC、耳机接口及已有数值门槛；未支持的明确硬要求不自动通过，不宣称无限自然语言核验。

最终决策可携带带引用的blocks，校验通过后复用以节省模型请求。缺引用编号或明确的结构错误可以从已核实前提生成最小候选引用集，再做完整校验或资料兜底；不修成显式坏编号，不新增模型重试。evidence_ids只支持本机事实；background_ids须注明原对象，不能为本机测量背书。标称、设定、实测数值，以及室温/设备温度、视频/音频/游戏时长分别核对。overview保留总体适配判断，不将“怎么样”作为测试题材。有限检查不证明任意自由表述都正确；提示词、原稿、拒绝、修复、版本与用量均留在轨迹中。

只有显式配置本地Embedding并加载可写外部索引时，官方参数与明确版本价可通过准入后增量入库；摘要和第三方评测不自动写共享索引。默认随包102款/478片段BM25，20款有价格、7款有评测；本地发现工具和回答详情说明覆盖限制，缺资料与不符合分别反馈。见 [资料覆盖](CORPUS.md)。

真实质量尚未全部通过。私人运行、历史失败与人工评审不随公开清单发布。离线回归不能代替真实语义或推荐质量验收；修过的原题属于回归集，不能当作盲测留出集。当前验证见 [修复记录](REPAIR_20261024.md)。

本轮语义focus_topics与完整条件分开保存；相机按镜头角色、屏幕/触控频率和有线/无线充电分别核对。历史真实失败保留原判，不因后续离线修复改称真实通过。
