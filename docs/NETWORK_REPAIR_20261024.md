## 一条证据路径，三种网页权限

已确认条件与当前问题 → 合并会话证据和所选本地检索 → 核对当前问题的缺口 → 按网页权限补查 → 合并新证据 → 统一条件/引用校验 → 回答当前问题。

Agent的工具和后续动作仍由模型决定，没有强制先搜某引擎或先抓某页。模型不可用时的固定资料路径复用同一搜索/抓取适配器，查询与抓取共享本轮上限；不无条件查全库，不扩大执行预算。候选资格、临时关注、明确比较和修改/取消条件继续由原状态机制管理。

| 页面 / API | 语义 |
|---|---|
| 关闭查询 / local | 不新增公开搜索或抓取；可以使用本地索引及本会话已取得的正文 |
| 按需查询 / auto | 允许按当前缺口决定是否查询，不强制本轮公开工具 |
| 本轮查询 / web | 请求本轮至少尝试一次公开查询，缓存、失败或未执行仍如实说明；不是刷新开关 |

页面默认local；API省略仍为auto，兼容原local/web请求和浏览器旧选择。用户明确“不联网/只用已有资料”优先。关闭公开网页查询不关闭DeepSeek，也不关闭选配的远程Embedding；默认BM25和本地BGE无需远程Embedding。工具操作、缓存与底层HTTP次数分别看待。

## 刷新和失败状态

ChatSource.refresh_status旧记录默认为not_requested。pending表示本轮尚待核对，verified表示取得新的正文记录；failed表示刷新未取得新记录，not_permitted表示未允许公开访问，not_attempted表示刷新未执行。价格失败时保留原记录与日期，并在回答/来源中明确为历史价；新推荐不能把该价格当作最新确认。失败不自动删除其他有效证据。

“需要无线充电”和“无线充电支持吗”都核对当前字段；旧游戏评测不能代替该字段。同样，询价失败也不能用游戏成绩冒充价格回答。新旧来源矛盾仍保留冲突，没有资料仍是未知；有限字段规则不宣称支持无限自然语言事实核验。

## 验证范围与剩余边界

新增跨路径回归覆盖local开始、按需补查、关网页继续问、刷新价格失败、冷恢复，以及条件修改/取消、候选更新。保存HTML的前后回放不发新外网请求、不调用模型。隔离本地页面实际切换三种模式并做一次资料问答；限30次本机HTTP和3次聊天POST，实际6次本机HTTP、1次聊天，含一次favicon 404；模型和外网均为0。页面检查不是模型自主Agent验收。

本轮没有新的真实外网HTTP验证，也没有真实模型自主多轮质量验收；没有重跑直到成功。测试中的模型和HTTP均为假依赖，外网被阻断；真实页面回放只证明这些已保存HTML的解析与状态行为。完整Python、前端、公开副本、链接与构建的最终结果分别记录，不相加、不改称推荐准确率。
